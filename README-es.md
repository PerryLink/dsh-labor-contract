# dsh-labor-contract

> **Repositorio oficial. El único repositorio oficial de este paquete, mantenido por PerryLink. Apache-2.0.**

</div>

Revisa la cobertura de cláusulas de un contrato laboral, el límite del período de prueba, el 80% del salario de prueba y la expiración de contratos en lote. Todo se ejecuta localmente y **no constituye asesoramiento jurídico**.

## Documentación completa

La documentación completa (instalación, permisos, ejemplos, formato CSV y solución de problemas) está en [README.md](README.md) y [README-zh.md](README-zh.md).
